# design — 배포되지 않는 보관물

여기 있는 것은 `public/` 이 아니므로 **웹으로 서빙되지 않는다.** 필요할 때 꺼내 쓴다.

## demos/
디자인 확정 과정의 시안 `demo.html` ~ `demo10.html` (demo10 이 확정본).
원래 `public/` 에 있어서 **주소만 알면 누구나 볼 수 있었다**(`/demo10.html` 이 200 을 반환했다).
내부 작업물이라 서빙 대상이 아니고, 옛 문구가 섞여 있어 실서비스로 오인될 여지도 있었다.

## legacy-img/img/
구 사이트 크롤에서 넘어온 이미지 212개(24MB). 소스에서 **한 곳도 참조하지 않는다**.
후기 본문에도 이미지 경로가 없다(확인함). 시안 5개가 이걸 참조하므로 같이 옮겼다.

## unused-hero/
`public/hero/` 에 있었지만 쓰이지 않던 5장(5.9MB) — `ai_leg_exam.png`, `bae-neo*.jpg` 3장,
`vd_hero_b.png`. 히어로 후보로 만들어 둔 것들이라 지우지 않고 옮겨만 뒀다.

## 참고
아버지가 보존을 원한 히어로 원본 5장(`slide_img*.jpg`)과 그 모바일 파생본은
계속 `public/hero/` 에 있다. 여기로 옮긴 것이 아니다.
